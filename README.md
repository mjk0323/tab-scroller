# 🎸 Tab Scroller

기타 타브 악보 PDF를 **BPM에 맞춰** 자동으로 스크롤해 주는 웹앱. (코드 운지표 표시는 개발 중)

PDF를 열면 타브 줄(6줄)과 마디선을 찾아서 줄마다 마디 수를 세고,
`줄 연주 시간 = 마디 수 × 박자 × 60 / BPM` 으로 줄 단위 속도를 맞춥니다.
마디 수가 틀리면 각 줄의 `−` `+` 배지로 고칠 수 있습니다.

**바로 쓰기:** https://mjk0323.github.io/tab-scroller/

PDF는 서버로 업로드되지 않고 브라우저 안에서만 열립니다.

## 단축키

| 키 | 기능 |
|---|---|
| `Space` | 재생 / 정지 |
| `↑` `↓` | BPM ±2 (수동 모드에선 속도 ±5) |
| `T` | 탭 템포 |
| `M` | BPM / 수동 모드 전환 |
| `Home` | 처음으로 |
| `F` | 전체화면 |
| `I` | 색 반전 (야간 모드) |
| `O` | 파일 열기 |

## 개발

```bash
npm install
npm run dev
```

`main` 브랜치에 push하면 GitHub Actions가 GitHub Pages로 자동 배포합니다.
