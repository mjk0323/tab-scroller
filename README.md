# 🎸 Tab Scroller

기타 타브 악보 PDF를 **BPM에 맞춰 자동 스크롤**하고, **코드 운지표**를 같이 보여주는 웹앱.

**바로 쓰기:** https://mjk0323.github.io/tab-scroller/

PDF는 서버로 업로드되지 않고 브라우저 안에서만 처리됩니다. AI·외부 API를 쓰지 않습니다.

## 하는 일

- **BPM 스크롤** — 타브 줄(6줄)과 마디선을 찾아 줄마다 마디 수를 세고,
  `줄 연주 시간 = 마디 수 × 박자 × 60 / BPM` 으로 줄 단위로 스크롤합니다.
  악보에 `♩ = 124` 같은 템포가 있으면 자동으로 BPM을 맞춥니다.
- **코드 운지표** — 악보의 코드명과 타브 숫자를 읽어서 운지 다이어그램을 그립니다.
  - 상단 바: 지금 코드 / 다음 코드를 크게 표시
  - 악보 위: 운지표가 인쇄돼 있지 않은 곳에만 그려 줌
  - **타브만 있는 악보**도 타브 숫자로 코드를 추론해서 같은 형태로 표시
- **곡별 기억** — 곡마다 BPM, 박자, 고친 마디 수를 브라우저에 저장

## 단축키

| 키 | 기능 |
|---|---|
| `Space` | 재생 / 정지 |
| `↑` `↓` | BPM ±2 (수동 모드에선 속도 ±5) |
| `T` | 탭 템포 |
| `C` | 코드표 켜기 / 끄기 |
| `M` | BPM / 수동 모드 전환 |
| `Home` | 처음으로 |
| `F` | 전체화면 |
| `I` | 색 반전 (야간 모드) |
| `O` | 파일 열기 |

## 한계

- 스캔한 이미지 PDF(텍스트가 없는 PDF)는 코드 인식이 안 됩니다 (스크롤은 됨). → OCR 필요
- 타브만 보고 추론한 코드는 아르페지오에서 7th·9th 음이 빠지면 단순한 코드로 나올 수 있습니다.

## 개발

```bash
npm install
npm run dev
```

`main` 브랜치에 push하면 GitHub Actions가 GitHub Pages로 자동 배포합니다. 로드맵은 [PLAN.md](PLAN.md).
